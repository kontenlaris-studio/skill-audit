What we check

  • Credential access — reads of .env, SSH keys, cloud credential files, keychains
  • Exfiltration shapes — the dangerous combinations: environment reads + network calls, file writes + uploads in the same code
  • Execution surface — shell commands, child processes, eval/exec, obfuscated or base64-hidden payloads
  • Network inventory — every external domain the skill talks to, listed and judged
  • Wallet traps — seed-phrase or private-key requests, which no legitimate skill ever needs
  • Documentation honesty — does SKILL.md disclose the env vars, network and writes the code actually performs?

How it works

Send the skill — email a GitHub link or a zip of the skill folder. Never send credentials or production secrets.
We scan and read — the deterministic scanner maps every risky pattern; a human then reads the code paths behind each finding to separate real risk from noise.
You get the verdict — a Markdown report within 48 hours: grade, findings with evidence, network inventory, and what to fix first.
